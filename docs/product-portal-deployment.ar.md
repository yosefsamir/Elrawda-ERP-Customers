# تشغيل استعلام EMOJI STORE وإدارة الصور

## ما أُضيف

- صفحة عامة للاستعلام، بدون حساب، بهوية EMOJI STORE الصفراء والسوداء.
- البحث بجزء من كود `mainfarz.ffarz` مع اقتراحات أثناء الكتابة، أو بالمطابقة الكاملة للرقم `maindet.iddet`؛ سعر البيع من `mainunits.fpr_r1`.
- الكود المدخل حروف إنجليزية وأرقام فقط. يمكن اختيار الاقتراح بالضغط عليه أو بالأسهم ثم Enter. الاقتراحات تبحث في كود الموديل فقط؛ لا تبحث جزئيًا في رقم الصنف.
- صفحة `/manage` لدخول مسؤولي الصور ورفع/حذف صور الصنف. الحسابات منفصلة عن حسابات الإدارة.
- إعدادات داخل لوحة الإدارة الحالية: اختيار الشركة المنشورة، تفعيل/إيقاف الاستعلام، عنوان البوابة، وإنشاء حسابات الصور وتعطيلها وإعادة تعيين كلمات مرورها.
- مدخل مستقل لا يسجل مسارات العملاء وWhatsApp وإعدادات SQL والصيانة.

## التشغيل المحلي

```sh
npm ci
npm run build
npm start
```

- الإدارة: `http://127.0.0.1:3211`.
- الاستعلام: `http://127.0.0.1:3212`.
- إدارة الصور: `http://127.0.0.1:3212/manage`.

في لوحة الإدارة اختر الشركة، واربطها بمصدر SQL من قسم الاتصالات إذا لم يكن مهيأ. من الإعدادات → «استعلام الموديلات وإدارة الصور» فعّل الاستعلام واحفظه، ثم أنشئ حساب مسؤول الصور. لا يُنشأ حساب افتراضي في الإنتاج. لا تسمح البوابة باختيار شركة أو قاعدة بيانات من الطلب العام.

يمكن ترك العنوان الخارجي فارغًا للتجربة المحلية. الصفحات تتوفر محليًا لكن الاستعلام وعمليات الحسابات لن تعمل ما دامت البوابة غير مفعلة.

بوابة الاستعلام تعرض شركة واحدة في كل مرة. اختيار شركة أخرى وحفظ إعدادات البوابة يلغي جلسات مسؤولي الصور القائمة. كل مستخدم صور مقيد بشركته. تعطيل الحساب أو تغيير كلمة مروره يلغي جميع جلساته.

الأسعار الصفرية أو غير المتاحة تُعرض «السعر غير متاح حاليًا»، ولا تُستبدل بسعر شراء أو حقل آخر. تُعرض الوحدات/النتائج المتعددة منفصلة، والصور تخص معرف الصنف والوحدة وهوية مصدر ERP معًا.

## Cloudflare والدومين الموجود

هذه الخطوات تنفذ على الجهاز الرئيسي وعند توفر حساب Cloudflare والدومين:

1. تأكد أن DNS للدومين على Cloudflare، مع حفظ سجلات الموقع والبريد الحالية إن احتاج الأمر نقل إدارة DNS. لا يتطلب ذلك نقل تسجيل الدومين.
2. حدد عنوانًا فرعيًا مثل `prices.example.com`.
3. في إعدادات البوابة المحلية أدخل `https://prices.example.com` بدون شرطة في النهاية واحفظه.
4. من Cloudflare → Networking → Tunnels أنشئ Tunnel دائمًا. اتبع أمر تثبيت `cloudflared` كخدمة Windows الذي تعرضه لوحة Cloudflare. token خاص بالخدمة؛ لا تضعه في المستودع أو رسائل الدعم.
5. أضف Published application route بالعنوان الفرعي، وخدمة `HTTP` وعنوان `127.0.0.1:3212`.
6. اترك Host header على العنوان العام الأصلي؛ لا تعدله إلى localhost. لا تضف Cloudflare Access أو شرط تسجيل دخول للرابط العام.
7. افتح `https://prices.example.com` من موبايل على بيانات الهاتف، وابحث بكود مؤكد. افتح `/manage` وجرّب حساب الصور.
8. تحقق أن `/api/company` و`/api/customers` و`/api/portal/users` و`/internal/shutdown` لا تعرض أي إدارة من هذا الرابط.
9. أعد تشغيل الجهاز وتحقق من تشغيل خدمة التطبيق وخدمة cloudflared ومن عمل الرابط مجددًا.

يُربط النفق ببورت 3212 فقط. لا تربطه ببورت الإدارة 3211 أو SQL Server. السيرفران يستمعان إلى loopback، فلا يلزم فتح بورت في الراوتر. يحتاج الجهاز واتصال الإنترنت للعمل طوال وقت استخدام الاستعلام.

مرجع الإعداد: https://developers.cloudflare.com/tunnel/get-started/

## التطوير والبورتات

- `npm run dev`: تشغيل السيرفرين.
- `npm run dev:web`: واجهة الإدارة أثناء التطوير.
- `npm run dev:portal`: واجهة الاستعلام أثناء التطوير على 5174.
- `PORT`: بورت الإدارة، الافتراضي 3211.
- `EMOJI_PORTAL_PORT`: بورت الاستعلام، الافتراضي 3212.
- في خدمة Windows يمكن إضافة `PortalPort` إلى `service.json` لتغيير بورت الاستعلام؛ الافتراضي 3212. حدّث مسار Cloudflare عند تغييره.

الواجهة الإنتاجية العامة تُبنى في `dist/portal` منفصلة عن `dist/web`. الإصدار المجمّع ينسخ مجلد dist بكامله، فيحتوي الواجهتين. يلزم تثبيت تبعيات الإنتاج الجديدة؛ مكتبة sharp تُستخدم لفك الصور والتحقق منها وإعادة ترميزها، ويُفحص عملها في preflight.

## الصور والنسخ الاحتياطي

- الصور محفوظة في `<dataDir>/product-images`، وليس داخل ملفات الإصدار ولا قاعدة ERP.
- PNG/JPEG/WebP فقط، حتى 5 MB و24 مليون بكسل للصورة، وبحد أقصى 10 صور لكل صنف ووحدة.
- يعاد ترميز الصور إلى WebP بأبعاد قصوى 1600×1600؛ لا تمرر ملفات المستخدم الأصلية مباشرة للمتصفح.
- الحذف يمنع عرض الصورة فورًا ويسجل العملية. تُحتفظ الملفات غير القابلة للتغيير داخليًا لضمان اتساق النسخ أثناء تشغيل النظام؛ لا تحذف ملفات هذا المجلد يدويًا.
- النسخ الاحتياطية القياسية تشمل الصور، والتحقق من النسخة يرفض النسخ التي ينقصها ملف لصورة فعالة. الاستعادة تعيد الصور مع قاعدة التطبيق.
- ترقية مخطط SQLite إلى الإصدار 3 تحتفظ بالشركات والحسابات الحالية، وتُنشئ لقطة `pre-v3` تلقائيًا عند الترقية من الإصدار 2. الإصدارات القديمة التي تدعم مخطط 2 فقط تحتاج نسخة ما قبل الترقية عند الرجوع.
