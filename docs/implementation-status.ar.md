# حالة التسليم — 1.0.0-rc.1

هذه نسخة مرشحة للتثبيت والقبول على Windows. أُصلحت مشاكل المراجعة في مسودة الإعدادات، واستئناف Preview، واختيار الطابور، ودفعات الجروب العام، وإعادة تشغيل حالات المراجعة، والنسخ الاحتياطي، وترقيم الجروبات، وحالات الاتصال والتقرير المتجدد.

أُضيف سجل SQLite دائم لعمليات الإضافة والدعوات وrollover مع منع تكرار الرقم/الوجهة. تُحجز حصة القديم قبل محاولة الكتابة، ولا تُكرر النتيجة المجهولة بعد الانقطاع. الإضافة المقبولة دون تأكيد عضوية تبقى pending؛ «فحص الحالة» يسوي العضوية قراءة فقط. الدعوة لا تظهر مرسلة دون نتيجة إرسال ومعرف رسالة.

المزامنة الجديدة كل 30 ثانية، والمصالحة الكاملة كل 60 دقيقة (ساعة)، مع زر مراجعة كاملة وتسجيل حالة فشل المزامنة. الإغلاق ينتظر العمل الجاري قبل إغلاق العامل والقاعدة، ويستخدم IPC للإغلاق المنظم على Windows. قفل البيانات يمنع تشغيل نسختين معًا.

البناء ينتج JavaScript للسيرفر والعامل، ويشمل المساعدين اللازمين. أدوات Windows تجهز اعتماديات production وChromium، وتشغّل Scheduled Task تحت SYSTEM، ونسخًا يومية، وتحديثًا بإصدارات منفصلة وتجربة ترحيل على نسخة، ورجوعًا للكود دون إرجاع البيانات تلقائيًا. يوجد backup متسق مع مفتاح SQL وrestore يوقف كل الشركات في Preview بعد الاستعادة.

فُحصت اختبارات المنطق ومختبر واتساب، وبناء الإنتاج، وتشغيل الملفات المبنية من مجلد مستقل دون سورس TypeScript، ودورة backup والتحقق والاستعادة وإعادة التشغيل وبقاء الحسابات والبيانات. فُحصت صياغة PowerShell؛ هذه ليست تجربة Task Scheduler أو SYSTEM على Windows فعلي. راجع سجل التحقق المصاحب للإصدار للأعداد والنتائج النهائية.

**القبول المتبقي عند العميل:** Windows x64 وNode 22.22+ ضمن 22.x، تثبيت Chromium وSQLite تحت حساب التشغيل، إعادة إقلاع الجهاز، اتصال SQL الحقيقي بحساب قراءة فقط، ورقم مصرح به لاختبار الإضافة والدعوة وrollover. يجب إتمامها قبل تفعيل Live. لا يوجد ضمان لصفر توقف أثناء تحديث السيرفر وعامل واتساب.

شعار الشركة متاح في الواجهة؛ تعيينه تلقائيًا للجروبات الجديدة وتاريخ المحادثات القديم غير مفعّلين. جلسة شركة واحدة نشطة في العامل. حزمة الإصدار لا تحتوي بيانات أو حسابات أو جلسات تطوير، وليست EXE أو حزمة Offline؛ الإنترنت مطلوب لأول تثبيت اعتماديات التشغيل.
