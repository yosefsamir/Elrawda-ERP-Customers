## أبرز الإضافات في 1.0.3
1. **بوابة الاستعلام والأسعار (EMOJI STORE):**
   - استعلام سريع عن تفاصيل وموديلات الأصعار وسعر البيع وصورها من قاعدة ERP.
   - مدخل منفصل وآمن على بورت 3212 لا يعرض أي بيانات إدارية أو اتصالات واتساب.
   - صفحة إدارة الصور `/manage` مع صلاحيات حسابات مستقلة.
2. **قارئ الباركود المتطور (Barcode Scanner):**
   - دعم كامل لقراءة كود Code 128 وتيكت الملابس.
   - محرك هجين سريع (سيرفر + متصفح) مع معالجة زوايا التصوير (0°، 90°، 270°) وانعكاسات الضوء.
   - معاينة فورية للصورة الملتقطة وإغلاق تلقائي فوري وفتح الصنف وسعره.
   - دعم الكاميرا المباشرة (Live Stream) عند الاتصال عبر HTTPS.
3. **جاهزية Cloudflare Tunnel:**
   - توثيق وإعدادات كاملة لنشر البوابة عبر نفق آمن ومجاني بدون فتح بورتات في الراوتر.
