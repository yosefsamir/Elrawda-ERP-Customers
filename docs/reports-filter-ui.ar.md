# محدد الأصناف والفروع

النطاق الحالي: **الفلتر فقط**. واجهة مختصرة بلا تقارير أو تسجيل دخول، بخط عربي واضح وشعار الشركة وتخطيط مناسب للهاتف.

## المعاينة

بعد `npm run build` وإعادة تشغيل التطبيق: `http://127.0.0.1:3212/reports/`.
للتطوير: `npm run dev:reports` يفتح `http://127.0.0.1:5175/reports/` ويمرر API إلى البورتال المحلي 3212.

الواجهة تحمل التعريفات من `/api/reports/filter-options`. زر تطبيق الفلاتر يعتمد التحديد محليًا فقط؛ لا يشغل استعلام أرصدة أو تقريرًا. لا تستبدل البيانات المتعذرة ببيانات توضيحية.

## مصدر ERP المحلي المؤقت

حتى تنفيذ جلسة التقارير المستقلة، الـAPI متاح من loopback فقط، بناءً على عنوان socket الفعلي مع اشتراط Host وOrigin محليين ورفض headers الخاصة بالـproxy، لأن Tailscale قد يتصل بـloopback أيضًا. لا يفتح بيانات ERP لأجهزة الشبكة أو Tailscale. لا يورث جلسة الأدمن أو الصور. يلزم تنفيذ مصادقة التقارير قبل إتاحة بياناته عن بعد؛ الصفحة الثابتة وحدها يمكن فتحها على مسار البورتال.

يحدد متغير السيرفر `EMOJI_REPORT_FILTER_CATALOG_FILE` ملف تعريفات صُدّر صراحة من المصدر المطلوب. لا يوجد fallback لشركة أو قاعدة أخرى. الملف خارج مجلدات static. الرد no-store، ومحتواه يتحقق بعقد محدود ويستبعد أي حقول إضافية. مصدر مفقود أو تالف يعيد 503، والمصدر السابق إن ظل ظاهرًا يوسم بأنه سابق وتتعطل الاختيارات حتى نجاح التحميل.

أداة استخراج التعريفات فقط، باستعلام SELECT ومعامل program وحد pool واحد ومهلة:

```sh
npx tsx scripts/export-report-filter.ts /private/sql-config.json /private/catalog.json 'نسخة ERP محلية · اسم القاعدة · البرنامج'
```

ملف الإعداد الخاص يحتوي `server,database,user,password,encrypt,trustServerCertificate,programId`، واختياريًا `port,instance`. لا توضع كلمات المرور أو ملفات الناتج داخل Git أو public. الأداة تغلق الاتصال حتى عند الخطأ، ولا تنشئ أي كائن في ERP. الملف الناتج نسخة ثابتة، وإعادة قراءته من الواجهة لا تعني تحديثه من SQL؛ لتحديث البيانات يعاد التصدير صراحة.

الشجرة مأخوذة من `kind → main → maincolor → mainsize → mainfarz → maindet`، والفروع من `branch + branchmain` والمخازن من `stor`. شرط البرنامج مطبق على الشجرة والفروع والمخازن. لا يستعمل `maindet.fvis` لاستبعاد الأصناف، لأن صنف الاختبار المعروف له حركة رغم أن العلم صفر. لا تُقرأ أرصدة أو أسعار أو بيانات عملاء. الأكواد النصية تحفظ رقم ERP؛ معرفات الواجهة مسبوقة باسم المستوى لمنع التصادم. المخزن يعرف ضمن فرعه.

في التجربة الحالية المصدر هو نسخة ElRawda المحلية، برنامج 9: 1169 صنفًا، 13 فرعًا، 31 مخزنًا. ليست اتصالًا مباشرًا بقاعدة العميل.

## المكونات

واجهة Controlled قابلة لإعادة الاستخدام من `apps/reports/src/components/catalog-filter/index.ts`؛ جلب البيانات خارج المكون. تدعم:

- تاريخ من/إلى واختصارات، بتوقيت القاهرة.
- Autocomplete بالاسم أو الكود، يختار أي مستوى ويكمل آباءه تلقائيًا.
- قوائم مترابطة، مسارات متعددة، اختيار الآباء والأبناء والاستبعاد الجزئي في الشجرة.
- فروع متعددة أو الكل، ومخازن تتبع الفروع المحددة.
- تطبيق محلي وإعادة ضبط وحالات تحميل وتعذر وإعادة محاولة.

بيانات demo متاحة للاختبارات فقط، ولا تستوردها واجهة التشغيل.

## التحقق

```sh
npm run typecheck
npm run test:reports
npm run build
npm run test:reports:browser
```

اختبار المتصفح يستخدم بيانات اختبار معزولة، ويغطي القوائم والبحث والكيبورد والشجرة والفروع والمخازن وخمسة عروض من 360 إلى 1280 بكسل. اختبارات السيرفر تغطي حماية عنوان الاتصال وتعذر المصدر وعدم تسريب الحقول الإضافية. راجع أيضًا البحث الحقيقي عن 186759 في واجهة التجربة: يكمل المسار حتى Z3330.
