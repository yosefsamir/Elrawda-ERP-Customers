# سجل تحقق 1.1.0-rc.2 — 3 نوفمبر 2026

هذا الإصدار يعالج موثوقية جلسات WhatsApp فوق الحالة المحلية السابقة `64a125b` التي تشمل خدمات الفواتير. تحليل السبب وحدود الإثبات في [تقرير موثوقية الجلسة](whatsapp-session-reliability.ar.md).

## المنفذ محليًا

- TypeScript وبناء backend وVite: ناجحان.
- suite المنطق والخادم: 128 اختبارًا ناجحًا من إجمالي 129، مع تخطي اختبار قفل Windows الحقيقي على Linux، ودون فشل. بينها 23 حالة لموثوقية WhatsApp (22 ناجحة + اختبار Windows المتخطى).
- مختبر WhatsApp: 20 اختبارًا ناجحًا دون حساب عميل.
- Chromium حقيقي: 4 اختبارات ناجحة للبروفايل والاسترداد وSocket والإغلاق المتوافق وتنظيف عملية مملوكة دون قتل متصفح آخر.
- العامل المبني وصل إلى QR جديد فعليًا دون مسحه أو ربط حساب أو إرسال أي رسالة.

## بوابة Windows

أضيفت اختبارات Chromium المحلية إلى workflow المثبت بعد البناء وقبل الحزم، مع اختبار FileStream مقفول في suite الأساسية على Windows. يبقى workflow الموجود مسؤولًا عن تثبيت Setup.exe والترقية وهوية LOCAL SERVICE والانقطاع الأولي وقت التشغيل وقتل العامل وحفظ البيانات.

لم يجر تثبيت أو إعادة تشغيل جهاز العميل، ولم يستخدم حساب WhatsApp مرتبط في هذه الجلسة. نجاح Linux لا يثبت تلك السيناريوهات على إنتاج Windows. لا يوصف Setup.exe بأنه جاهز للعميل إلا بعد نجاح البناء والاختبار في CI.
