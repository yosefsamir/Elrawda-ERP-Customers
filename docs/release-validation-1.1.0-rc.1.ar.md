# سجل تحقق 1.1.0-rc.1 — 3 نوفمبر 2026

## المنفذ محليًا

- TypeScript والبناء الإنتاجي ناجحان.
- 106 اختبارات للمنطق والخادم ودورة التشغيل، منها 45 للفواتير والترقية والطوابير و13 للسحب المحدود والاستكمال.
- 20 اختبارًا لمختبر واتساب باستخدام محاكاة، دون الاتصال بحساب العميل أو إضافة أشخاص حقيقيين.
- ترقية fixture مستقل بمخطط v2 إلى الامتداد الجديد، وتكرار الفتح، وحفظ القيم القديمة حرفيًا، والتراجع الذري عند فشل الترحيل.
- اختبارات الصلاحية، الطباعة المتأخرة، إيقاف المعالجة، العضوية المؤكدة/المعلقة، الاستبعاد الدائم، تداخل الطوابير، العودة متأخرًا وتوزيع بقية اليوم، وفشل المحاولات.
- اختبار backup/restore لحالة الطوابير، ومنع رجوع إصدار غير متوافق بعد تفعيلها.
- متصفح Chromium فعلي ببيانات اختبار محلية: سبع صفحات إعدادات، عزل حقول كل خدمة وحفظ نص الرسالة وساعات العمل دون الكتابة فوق إعدادات غيرها، غياب زر التشغيل العام، والتحقق من إرشادات الربط. دون أخطاء JavaScript أو تجاوز عرض الصفحة على سطح المكتب والهاتف بعرض 390 بكسل.
- تحليل صياغة سكربتات PowerShell الستة عشر داخل PowerShell 7.4، دون تنفيذ تثبيت على جهاز العميل.

- اختبار إضافي على SQL Server 2022 مع قاعدة صناعية معزولة من 12,125 فاتورة: صفحات محدودة، تواريخ متساوية، أكواد تتجاوز دقة JavaScript، تعديل الطباعة والحذف، وفاتورة جديدة بكود أقل. لم يستخدم بيانات العميل أو يكتب في ERP الحي.
- اختبارات تراكم أكثر من 50 فاتورة والاستكمال بعد إعادة التشغيل، وعدد النتائج الكلي للدورة، وحجز جزء للحديث أثناء المتراكم، والتراجع الذري عند فشل حفظ نقطة التقدم، وتدوير مراجعة بيانات العملاء الناقصة.

## لم يُثبت بعد

- اختبار المثبت والتحديث والاستكمال على Windows فعلي، تحت هوية الخدمة وTask Scheduler.
- التحديث على نسخة قاعدة التطبيق من الإصدار المثبت عند العميل فعلًا، واستمرار جلسة واتساب الخاصة به.
- تنفيذ استعلامات الموصل الجديد على ERP الحي وقياس زمنه وحمله وخطة التنفيذ والفهرس المناسب للتاريخ. حد 50 للنتائج لا يثبت عدد الصفحات المقروءة داخليًا. الفحص السابق كان على snapshot منفصل؛ اختبارات المزامنة الجديدة تستخدم موصلات محاكاة.
- إرسال رسائل فواتير على حساب حقيقي؛ الخدمة متوقفة افتراضيًا، ومسار التنفيذ واختبارات التفعيل والإيقاف واكتمال الربط تعمل بموصل واتساب محاكى.

يظل الإصدار مرشح اختبار إلى أن يكتمل قبول Windows ونسخة بيانات العميل. راجع دليل الانتقال قبل التحويل من وضع التوافق.

- اختبار تشغيل الحزمة من مسار معزول نجح: HTTP والواجهة، backup متسق أثناء WAL، التحقق والاستعادة، probe، إعادة التشغيل وبقاء الحساب والشركة، وإغلاق منظم.
- تجهيز الأصول التنفيذية لـWindows يستخدم runtime واعتماديات من الإصدار المحلي السابق بعد مطابقة جميع اعتمادات lockfile والتحقق من SHA256 للأصول، دون إعادة استخدام كود التطبيق القديم. هذا يثبت سلامة الأصول المنسوخة ولا يثبت تشغيلها على Windows في هذه البيئة.
