# سجل تحقق 1.0.1 — 3 نوفمبر 2026

إصلاح WhatsApp مستقل مبني مباشرة على `main` عند `cf84a6b` (1.0.0). لا يشمل commit الفواتير `64a125b` أو ملفاته أو ترحيلاته أو اختباراته، ولم يجر دمج ذلك الفرع في main.

تحليل السبب وحدود الإثبات: [تقرير موثوقية جلسة WhatsApp](whatsapp-session-reliability.ar.md).

## التحقق

أعيد التحقق على قاعدة main المستقلة: TypeScript والبناء ناجحان؛ 70 اختبارًا أساسيًا ناجحًا من أصل 71 (اختبار Windows المقفول متخطى على Linux)، و20 اختبارًا لمختبر WhatsApp و4 اختبارات Chromium حقيقية ناجحة، ودون فشل. لم تشغل اختبارات فرع الفواتير في هذا الإصدار.

اختبارات Chromium الفعلية تستخدم بروفايلات صناعية بلا حساب عميل: بقاء البيانات عبر إعادة الفتح، والانقطاع، وتعطل المتصفح؛ انتظار Socket؛ وإغلاق المتصفح بالـAPI الصحيحة دون قتل متصفح مستقل. اختبار Windows الخاص يمسك ملفًا بمقبض FileShare.None ويختبر الانتظار المحدود؛ يتخطى على Linux.

لم يجر تثبيت أو إعادة تشغيل جهاز العميل أو إلغاء ربط هاتفه. تبقى استعادة جلسة WhatsApp مرتبطة فعليًا بعد reboot أو تحديث Windows بحاجة للتحقق الميداني. يبنى Setup.exe جديد باسم WhatsAppERP-Setup-1.0.1.exe من main بعد رفع الإصلاح، باستخدام المثبت ومسار بيانات ProgramData وAppId القائمين.

النسخة السابقة من فرع الإصلاح المبني على فرع الفواتير (1.1.0-rc.2) ليست نسخة هذا الإصدار ولا تستخدم لتنزيل الإصلاح الحالي عند العميل.
